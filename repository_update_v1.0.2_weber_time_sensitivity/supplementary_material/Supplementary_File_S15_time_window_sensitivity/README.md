# Supplementary File S15: Time-window and calendar-period sensitivity analyses

This folder contains the supplementary outputs for the launch-period / Weber-type reporting sensitivity analysis.

Files:
- `Supplementary_File_S15_summary.md`: narrative summary and interpretation.
- `Supplementary_File_S15a_time_restricted_pairwise_2017Q1_onward.csv`: pairwise vortioxetine-vs-comparator 2 × 2 counts and RORs after retaining FDA_DT >= 2017-01-01.
- `Supplementary_File_S15b_time_restricted_pooled_class_2017Q1_onward.csv`: pooled SSRI/SNRI class comparisons after retaining FDA_DT >= 2017-01-01.
- `Supplementary_File_S15c_time_restricted_vortioxetine_vs_escitalopram_by_sex.csv`: sex-stratified vortioxetine-vs-escitalopram results after retaining FDA_DT >= 2017-01-01.
- `Supplementary_File_S15d_calendar_period_vortioxetine_vs_escitalopram.csv`: calendar-period vortioxetine-vs-escitalopram results.
- `Supplementary_File_S15e_time_restricted_cohort_counts.csv`: compact cohort counts for the time-restricted analysis.

Raw FAERS/AEMS files are not included because they are publicly available from FDA. The manuscript's reproducibility repository contains the analysis scripts and configuration files.
