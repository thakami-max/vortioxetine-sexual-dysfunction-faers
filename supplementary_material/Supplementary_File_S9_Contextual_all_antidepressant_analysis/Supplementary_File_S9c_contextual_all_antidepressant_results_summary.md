Supplementary File S9c. Contextual all-antidepressant analysis summary

This contextual analysis is not the primary analysis. It is included to document the broader all-antidepressant FAERS/AEMS signal context.

Contextual narrow PS+SS all-antidepressant analysis
- Deduplicated FAERS/AEMS cases: 16,002,134.
- Antidepressant exposure rows matched: 507,019.
- Unique antidepressant-exposed cases: 390,373.
- Sexual-dysfunction event rows matched: 52,711.
- Unique sexual-dysfunction event cases: 40,676.
- Vortioxetine vs full FAERS/AEMS background: ROR 14.39, 95% CI 13.24-15.64.
- Vortioxetine vs other antidepressants: ROR 1.91, 95% CI 1.76-2.09.

Contextual PS-only all-antidepressant sensitivity
- Vortioxetine vs full FAERS/AEMS background: ROR 14.70, 95% CI 13.44-16.07.
- Vortioxetine vs other antidepressants: ROR 1.49, 95% CI 1.36-1.64.

Contextual broad-outcome all-antidepressant sensitivity
- Sexual-dysfunction event rows matched: 59,197.
- Unique sexual-dysfunction event cases: 46,095.
- Vortioxetine vs full FAERS/AEMS background: ROR 12.74, 95% CI 11.73-13.85.
- Vortioxetine vs other antidepressants: ROR 1.77, 95% CI 1.62-1.92.

Interpretation
These broad analyses are provided only as contextual supplementary material because the main manuscript focuses on selected active comparators with depression-indication restriction.
